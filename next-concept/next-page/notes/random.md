# what is Time To First Byte means

```
The time it takes for a user's browser to receive the very first byte of data from the server after making a request
```

# What is a CDN (Content Delivery Network)

A CDN(Content Delivery Network) is a network of servers distributed across the globe that stores and delivers websites's static content (like images, CSS, Javascript, Videos, and even pre-rendered HTML pages)

**_Note:-_**

```
Instead of all users connecting to one centeral server, a CDN delivers content from the server closest to the user's location.
```

# Benefits of a CDN

1. Faster performance (low latency, low TTFB)

   - Content comes from the closest server, not the origin server far away.

2. Scalability

   - Millions of users can access cached copies from different servers without overloading your main server.

3. Reliability
   - If one server goes down, another nearby CDN node serves the content.
4. SEO boost
   - Since speed improves, search engines rank your site better.
